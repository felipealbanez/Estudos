\# Projeto Final do Módulo 3 - Fundamentos de Machine Learning



\## Sobre o projeto



Inicialmente este projeto foi desenvolvido como trabalho final do curso Técnicas de Programação I cujo o objetivo é realizar uma análise exploratória de dados utilizando Python, Pandas, NumPy e Matplotlib sobre as candidaturas das Eleições de 2022.



O projeto foi aprimorado para ser a entrega final do módulo 3 cujo o objetivo é realizar uma análise de dados completa e aplicar um modelo de Machine Learning.





\## Bases utilizadas



Link: https://dadosabertos.tse.jus.br/dataset/candidatos-2022



Base principal contendo informações gerais das candidaturas:

consulta\_cand\_2022\_BRASIL.csv



Bases auxiliares utilizadas para informações de idade e valor de despesa:

consulta\_cand\_complementar\_2022\_BRASIL.csv

bem\_candidato\_2022\_BRASIL.csv
